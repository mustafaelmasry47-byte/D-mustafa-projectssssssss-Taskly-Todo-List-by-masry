# Taskly - To-Do List

قائمة مهام عربية بسيطة وأنيقة باستخدام:
- HTML
- CSS
- JavaScript

## التشغيل
افتح ملف `index.html` مباشرة في أي متصفح.

## المميزات
- إضافة وحذف وتعديل المهام.
- تحديد المهمة كمكتملة.
- تصنيف الأولوية: مهمة / عادية / منخفضة.
- فلترة: الكل / قيد التنفيذ / مكتملة.
- عدادات وإحصائيات تلقائية.
- حفظ المهام باستخدام LocalStorage.
- الوضع الليلي.
- Responsive للموبايل والتابلت والكمبيوتر.

لا يحتاج المشروع إلى سيرفر أو قاعدة بيانات.
